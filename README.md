# 🚀 Django Portfolio

A modern, dynamic, and fully responsive personal portfolio web application built with **Django**. Designed to showcase professional background, technical skills, projects, and contact information with clean backend architecture and an intuitive admin management system.

---

## 🌟 Features

- **Dynamic Project Showcase:** Display featured projects with descriptions, tech stacks, and live links managed straight from the Django Admin panel.
- **About & Skills Section:** Highlight professional experience, education, and technical expertise (Python, Django, JavaScript, React, etc.).
- **Interactive Contact Form:** Allows visitors to send messages directly, storing inquiries in the backend database.
- **Admin Dashboard:** Fully customizable CMS for managing portfolio content, projects, and messages without touching code.
- **Responsive Design:** Built to look polished and professional across all devices (desktops, tablets, and mobile screens).

---

## 🛠️ Tech Stack

- **Backend:** Python, Django
- **Database:** SQLite (Development) / PostgreSQL (Production ready)
- **Frontend:** HTML5, CSS3, JavaScript, Tailwind CSS / Bootstrap
- **Deployment:** PythonAnywhere / Render / Vercel
